# 1. Business Understanding
- Objective: Define the problem statement, business goals, and success metrics.
- Action: Align with stakeholders to turn a business problem into a measurable data task.

# 2. Data Mining
- Objective: Extract raw, hidden patterns and information from large datasets.
- Action: Query relational databases, scrape web data, or ingest unstructured log files.

# 3. Data Cleaning
- Objective: Improve data quality by removing errors, noise, and inconsistencies.
- Action: Handle missing values, eliminate duplicates, and correct formatting anomalies.

# 4. Data Exploration (EDA)
- Objective: Analyze the dataset characteristics and find initial relationships.
- Action: Calculate summary statistics (mean, median) and spot outliers or distributions.

# 5. Feature Engineering
- Objective: Transform raw data into meaningful variables that improve model performance.
- Action: Normalize numeric scales, encode categorical data, and combine fields to create new predictors.

# 6. Predictive Modelling: Training Dataset
- Objective: Teach a machine learning algorithm to recognize patterns and make predictions.
- Action: Fit mathematical models (e.g., Random Forests, Regressions) strictly on training data subsets.

# 7. Data Visualization
- Objective: Communicate complex data insights and model findings clearly to decision-makers.
- Action: Build interactive dashboards (Tableau/Power BI) and generate static charts (Seaborn/Matplotlib).
